# RTFH brand assets

Downloaded from the official RTFH website for this internal dashboard, at the user's request. The original artwork is unchanged.

- Full logo: https://www.rtfhsd.org/wp-content/themes/RTFH/images/LogoTop.svg
- Compact house mark: https://cdn.www.rtfhsd.org/wp-content/uploads/2024/08/26160209/cropped-Full-Color-House-White-Background-RTFH-Logo-17-icon-192x192.png
- Website: https://www.rtfhsd.org/

The SVG defines blue `#0075C2`, cyan `#00CED1`, gold `#F8C02A`, purple `#8D3188`, and green `#20AF90`. The dashboard uses these brand colors with light background tints and darker text variants for readability. Error and overdue states retain distinct semantic colors.
